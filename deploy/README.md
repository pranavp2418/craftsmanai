# Hostinger VPS deployment

The live system currently uses Nginx, PM2, PostgreSQL 16, and Redis on Ubuntu. The monorepo migration changes application paths only. It does **not** move the PostgreSQL database, Redis data, or Supabase Storage.

## Required preservation before cutover

Create recoverable backups of:

- `/root/backend/.env`
- `/root/backend/uploads/` (8 fallback objects were present during the audit)
- the active Nginx site configuration
- the PM2 process dump
- PostgreSQL using `pg_dump`

Do not commit any copied `.env`, database dump, or uploaded customer file.

## Intended server layout

```text
/root/craftsmanai/
├── frontend/
├── backend/
│   ├── .env
│   ├── uploads/
│   └── venv/
├── deploy/
└── logs/
```

## Build preparation

```bash
cd /root/craftsmanai
mkdir -p logs backend/logs backend/uploads

cd frontend
pnpm install --frozen-lockfile
pnpm build

cd ../backend
python3 -m venv venv
venv/bin/pip install -r requirements.txt
venv/bin/python -m compileall app
```

Copy the existing production `.env` and fallback uploads only after the fresh checkout is prepared. Do not replace the existing application directories during this stage.

## Cutover

1. Put the existing site in a maintenance window if database migrations are required.
2. Apply reviewed Alembic migrations. The source repository currently lacks committed `alembic/versions` files, so do not run an autogenerated migration against production without first reconciling the live schema.
3. Merge `nginx-locations.conf` into the existing TLS server block and validate with `nginx -t`.
4. Start or reload all five processes:

   ```bash
   cd /root/craftsmanai
   pm2 startOrReload deploy/ecosystem.config.cjs
   pm2 save
   ```

5. Reload Nginx only after validation: `systemctl reload nginx`.
6. Verify the homepage, login/refresh flow, `/api/v2/endpoints/health`, Socket.IO, SSE, Supabase images, and one `/uploads/` fallback image.

Keep `/root/frontend` and `/root/backend` unchanged until the new deployment passes verification and rollback is no longer needed.
